# My First Python Project

A beginner Python project created while learning programming and AI development.

## Features

- Greets the user by name.
- Asks what the user wants to build.
- Introduces basic Python input and output.

## Requirements

- Python 3

## How to run

Open a terminal in the project folder and run:

```bash
py main.py
```

## What I learned

- Using `print()` to display messages.
- Using `input()` to collect user responses.
- Storing information in variables.
